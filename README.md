# WearAyo storefront mockup

A responsive React + Vite storefront concept for WearAyo. Product names, availability, and prices are sample mockup content; sneaker photos load from Unsplash.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. To create a production build, run `npm run build`.

## Included interactions

- Filter sample sneakers by brand new and pre-loved
- Add or remove pairs in the bag
- Continue a sample order through WhatsApp
- Responsive navigation and sample email signup feedback
